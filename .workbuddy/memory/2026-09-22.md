# 2026-09-22

## DouyinLiveRecorder 重构 + Electron 桌面端（承接上一轮，本轮补齐「桌面集成层」）

### 背景
上一轮已完成：`dylr/` 后端重构（平台注册表 / 配置元数据 / 任务状态机 / 标准库 HTTP+SSE 接口）
与 `electron/` 桌面端六个页面。本轮验收时发现：功能齐了，但**缺少让录制工具真正能挂机的那一层**。

### 本轮做的事

**1. 应用图标（原本一个位图资源都没有）**
- 新增 `electron/tools/make_icons.py`：纯标准库手写 PNG 编码器 + 距离场渲染，
  生成 `assets/icon.png(256)`、`icon.ico(16~256 多尺寸 ICO)`、`tray.png(16)`、`tray@2x.png(32)`。
- 字形复用应用内标题栏 logo 的「广播波 + 直播点」比例，配色取 CSS 变量（accent #5b8cff / live #ff4d5e）。
- 踩坑：① alpha 忘了 ×255 导致整图近乎全透明；② `simplified` 参数没传进几何函数，
  32px 托盘用了「四弧细描边」版，糊成一团；③ 左弧跨 ±180° 时 `atan2` 返回负角，
  区间判断失败导致下半段弧描边断裂（改为以 a0 为原点归一化到 [0,2π) 再比）。

**2. 系统托盘 + 关闭到托盘**（`electron/src/tray.js`）
- 原实现关窗即退出 → 挂机录制直接断，这是最影响实际使用的问题。
- 托盘：显示/隐藏、开始/暂停全部、打开录制目录、退出；悬浮提示实时显示「录制中 N · 等待 M」。
- 关闭窗口默认最小化到托盘（可在设置里关掉），并给一次气泡提示。

**3. 系统通知**（`electron/src/notifications.js`）
- 开播 / 录制结束（含时长体积）/ 任务异常 / 磁盘告警。
- 「要不要打扰」的判断放主进程（只有它能知道窗口是否前台/隐藏），渲染层只上报事件。
- 首次见到某任务只登记不通知（否则每次启动都狂弹）；同内容 5 秒去重。

**4. 偏好与窗口状态持久化**（`electron/src/prefs.js`，渲染层镜像 `renderer/js/prefs.js`）
- 存 `userData/desktop-prefs.json`，**不写进 config.ini**（那是录制核心的配置，会被 CLI 和上游读写）。
- 记住窗口几何；多显示器拔插后校验可见区域交集，避免窗口跑到屏幕外。
- `backgroundThrottling: false`：托盘状态下仍要按秒更新状态、及时弹通知。

**5. 设置页新增「桌面端」本地分组**
- `LOCAL_GROUP` 插在后端分组之前；开关即时生效，所以不进未保存队列，
  页头也不再显示按不动的「保存」（靠 `settings:group-changed` 事件让外壳重绘页头）。
- 依赖总开关的细分项置灰不消失（位置固定，用户不会找不到）。

**6. 启动引导改为显示后端真实里程碑（顺手修了一个「不实」的文案）**
- 发现：`--print-port` 路径下后端就绪前一行都不输出，且 ffmpeg 自检只在终端 banner 里，
  这条路不走 banner → 「启动时自检过了」是空话，缺 ffmpeg 要开始录才暴露。
- 后端新增 `DYLR_STAGE <文本>` 协议（`dylr/service.py`），并真正执行环境自检；
  为此把 `Service.start()` 拆成 `start_api()` / `start_manager()`。
- `backend.js` 解析该前缀（与 `DYLR_READY` 放一起），走独立的 `backend:stage` 通道；
  状态快照带 `stages` 以便晚注册的渲染层补齐；问题用「注意：」前缀 → 界面用告警色。
- 启动页同时显示已用时长、后端原始输出（可复制）、真实步骤清单。

### 工具链踩坑（重要，环境相关）
- **宿主注入了 safe-delete shim**：`fs.rmSync`/`rm` 被劫持去走回收站，这里会抛
  `Some operations were aborted`。脚本里**不要删文件**（`check-js.mjs` 改成只写不删）。
- **不要用 `taskkill` 杀进程**：会误伤用户自己跑的 python/electron，而且反复触发权限确认。
  抓图改为「独立启动 + 抓完自己退出」，脚本里彻底移除 taskkill。
- **给 Electron 传路径必须用 `D:/...`**：MSYS 的 `/d/...` 它不认，会导致进程静默退出、日志为空。
  脚本里统一用 `pwd -W`。
- 抓图模式（`--capture`）现在**不显示窗口**，可以随手跑而不打扰用户。
